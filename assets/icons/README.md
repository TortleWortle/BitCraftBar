# Icons

Monochrome SVGs, drawn by GPUI as masks in the current text color
(`src/assets.rs` embeds them).

- `skills/<skill id>.svg`: BitCraft's own skill glyphs (the game's icon
  font; `skill_desc.icon_asset_name` is the code point, e.g. Forestry =
  U+FFEA). Taken from the font export in the fan site brico
  (`BitCraftToolBox/brico`, `frontend/src/components/icons/font-icons-data.ts`).
  Game art © Clockwork Labs. No glyph for skill 1 ("Any").
- `heart.svg`, `food.svg`, `compact.svg`, `expand.svg`: Material Icons
  shapes (favorite, restaurant, close_fullscreen, open_in_full; Apache 2.0).
